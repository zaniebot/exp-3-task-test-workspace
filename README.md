# sandbox

A Rust utility library providing common math functions, including Fibonacci sequence computation, primality testing, and greatest common divisor (GCD) calculation.

## Functions

- **`fibonacci(n)`** – Computes the nth Fibonacci number using an iterative approach.
- **`is_prime(n)`** – Returns whether a given number is prime.
- **`gcd(a, b)`** – Computes the greatest common divisor of two numbers using the Euclidean algorithm.

## Build

```sh
cargo build
```

## Test

```sh
cargo test
```

## Run

```sh
cargo run
```
