# Task Test Workspace

A test workspace for the agent task queue system.

## Scripts

### hello.py
A simple script with `main()` and `goodbye()` functions. `main()` prints a hello message and `goodbye()` prints a goodbye message. Both are called when the script is run directly.

Run it with:
```bash
python hello.py
```

To greet someone by name, use the `--name` flag:
```bash
python hello.py --name Alice
```
This will print `Hello, Alice!` instead of the default message.
